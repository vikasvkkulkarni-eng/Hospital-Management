# 🏥 Medi Track Analytics – Hospital Management Dashboard

## 📌 Project Overview
An interactive Power BI dashboard that analyzes hospital data across
patients, doctors and visits to track appointments, revenue, payment
collection and no-show/cancellation rates.

## 🎯 Objective
Help hospital management monitor performance, find revenue gaps, and
reduce appointment losses with data-driven insights.

## 🛠️ Tools Used
- Power BI Desktop
- DAX
- Power Query
- Star-schema data modeling

## 📊 KPIs
- Total Patients
- Total Appointments
- Total Revenue
- Revenue Collected
- Revenue Pending
- No-Show Rate %

## 🔍 Slicers
Specialization, Hospital Branch, Payment Method, Treatment Type,
Insurance Provider, Gender

## 📈 Visuals
- Monthly appointment trend (line chart)
- Appointment status (donut chart)
- Revenue by specialization, doctor and branch
- Payment method vs payment status
- Patient gender split
- Doctor-wise no-show and cancellation table
